# Jozi Bakes

Premium single-page website for **Jozi Bakes** — a home bakery in Kharghar, Navi Mumbai.

Phase 1: full-screen, app-like hero with a 3D Spline diorama of the bakery, starring **Jozi** (the baker) and **Bruno** (the dog). The Spline runtime plays their authored idle animations while the camera gently orbits the centred diorama on a slow turntable. Tapping smoothly pushes the camera into a centred close-up of Jozi and floats her RPG-style quick-order menu up beside her; tapping again eases back out to the turntable.

## Stack

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS v4
- `@splinetool/react-spline` (Spline runtime; tap-driven camera turntable + close-up)
- Deployed on Vercel

## Develop

```bash
npm install
npm run dev
```
